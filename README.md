💰 Expense Tracker

A simple Expense Tracker built as my first project and my first experience publishing a project publicly using Git and GitHub.

It is a basic project, but it has a special place in my learning journey because it represents one of my first steps from learning programming to actually building and sharing something of my own.

---

📌 About the Project

The goal of this project is to create a simple application for keeping track of expenses.

This project was mainly built to practice:

- Writing actual application code
- Working with a backend
- Understanding project structure
- Using Git for version control
- Using GitHub to manage and publish a project
- Getting comfortable with making commits and tracking changes

It is not intended to be a production-level expense management system. Instead, it is a learning project that helped me understand how the different pieces of a software project fit together.

---

✨ What I Learned

Building this project taught me more than just how to write the code.

Some of the things I learned while working on it:

- How to structure a project
- How a backend application works
- How to work with Django
- How URLs, views and templates interact
- How to use Git to track my development
- How to push a project to GitHub
- How to debug problems that appear while building an actual project

Most importantly, I learned that building something yourself is very different from simply following a tutorial.
